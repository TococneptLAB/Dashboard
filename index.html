ยังไม่ได้เชื่อมต่อฐานข้อมูลส่วนกลาง

ไฟล์นี้ต้องเชื่อมกับ Google Sheets (ทำครั้งเดียว) เพื่อให้พนักงานทุกคนเห็นข้อมูลชุดเดียวกัน:

  1. สร้าง Google Sheet ใหม่ 1 ไฟล์
  2. เมนู Extensions → Apps Script แล้ววางโค้ดจากไฟล์ GoogleAppsScript_Code.gs ที่แนบมา
  3. Deploy → New deployment → Web app → Execute as "Me", Who has access "Anyone"
  4. คัดลอก Web app URL (ลงท้าย /exec)
  5. แก้ไฟล์ HTML นี้: หาบรรทัด const API_URL = "" แล้ววาง URL ลงไป บันทึก แล้วแจกไฟล์นี้ให้พนักงานเปิด
  6. กลับไปที่ Google Sheet เปิดชีท "Employees" เพิ่มชื่อ + PIN พนักงานแต่ละคน

รายละเอียดทั้งหมดอยู่ในคอมเมนต์ต้นไฟล์ .gs ที่แนบมาด้วย
